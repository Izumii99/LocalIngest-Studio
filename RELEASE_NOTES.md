# LocalIngest Studio — Release Notes

## Version 1.0.4

This release introduces an iconic, high-craft brand identity redesign, professional social preview assets, and distribution packaging updates.

### What's New & Highlights:

- **New Brand Identity & High-Craft Logo**:
  - Replaced legacy placeholder marks with an iconic, geometric brand emblem engineered under professional design standards.
  - Features the tactile Local Code Bracket (`<`), the Cyber Mint Ingestion Chevron (`>`), and the Radiant Amber Intelligence Core (`✦`), symbolizing offline local code ingestion distilled into pristine AI context.
  - Rendered at ultra-high resolution (1024x1024) and optimized for razor-sharp clarity across all scaling ladders (desktop icon, taskbar, dock, and 16px favicon).

- **Official Social Preview Assets (`social.png`)**:
  - Added an official 1200x630 Open Graph / GitHub social preview banner featuring the new brand emblem, feature highlights, and neo-brutalist dark tech aesthetic.

- **Automated Metadata & Asset Sanitization**:
  - All distributed brand images are 100% sanitized via the automated pipeline, stripping EXIF, XMP, IPTC, and generator metadata traces for clean open-source distribution.

- **Packaging & Executables**:
  - Updated all Windows standalone binaries:
    - **`LocalIngest-Studio-Portable-v1.0.4.exe`**: Zero-install, single executable for Windows 10/11.
    - **`LocalIngest-Studio-Setup-v1.0.4.exe`**: Interactive installer with directory customization, shortcut options, and confirmed uninstaller.
    - **`LocalIngest-Studio-Linux-v1.0.4.AppImage`**: Standalone Linux binary.
